## 🛠️ Tools Used

- **Language:** Java
- **Editor:** Sublime Text
- **Execution:** Windows Command Prompt (CMD)
- **Version Control:** Git and GitHub

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Open Command Prompt in the folder containing the Java file.
3. Compile the program:

   ```bash
   javac FileName.java
   ```

4. Run the program using its class name:

   ```bash
   java ClassName
   ```

   Replace `FileName` and `ClassName` with the actual names used in your program.
